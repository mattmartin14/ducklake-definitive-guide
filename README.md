### DuckLake - The Definitive Guide Code Repository

This is the code repository that provides examples illustrated in the book "DuckLake - The Definitive Guide"

Most of the sql command in this repository can be executed by DuckDB's CLI with the following command:

```bash
duckdb -c ".read the_file.sql"
```

For python code examples, we are using UV as the package manager. To execute those examples, simply run:

```bash
uv run the_file.py
```
