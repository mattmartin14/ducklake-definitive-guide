on a mac, to get ducklake pg going, do the following:

1. install postgres using home brew
- brew install postgresql

2. start postgres under the default db with psql
- psql -d postgres

3. create a ducklake database
create database ducklake_v1

4. close pg connection
\q

5. run the python to attach the ducklake postgres db and make some data

6. log back into pg under the ducklakedb
- psql -d ducklake_v1 -P pager=off

8. to see all the tables in the ducklake schema, run select * from information_schema.tables

some tables to sample

ducklake_metadata
ducklake_tables
ducklake_column

full schema spec is here: https://ducklake.select/docs/stable/specification/tables/overview
